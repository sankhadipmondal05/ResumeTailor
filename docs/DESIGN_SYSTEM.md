# Design System

## Direction

Professional, minimal, productivity-oriented. Light mode only.

## Colors

Background: #FFFFFF
Primary text: #111111
Secondary text: #5F6368
Muted text: #8A8F98
Border: #E4E6E8
Surface: #F7F7F8
Primary accent: #4F46E5
Accent hover: #4338CA
Success: #16803C
Warning: #A16207
Error: #B42318

## Typography

UI font: Inter, fallback Arial, sans-serif.
UI: 14px
Small: 12px
Section title: 18px
Page title: 28px

Resume preview defaults to Arial. Allow Calibri and Georgia as alternatives.

## Dimensions

Desktop sidebar: 240px
Topbar: 64px
Page horizontal padding: 32px
Maximum content width: 1440px
Card radius: 10px
Button radius: 8px
Input radius: 7px
Icon size: 18px

## Spacing

Use an 8px system: 8, 16, 24, 32, 40, 48, 64.

## Styling

Prefer subtle 1px borders. Avoid heavy shadows. Use shadows only for dropdowns, modals, and floating UI.

## Resume Preview

A4 210mm × 297mm, white document, subtle workspace shadow, no decorative frame inside the document.

## Accessibility

Use semantic HTML, labels, keyboard navigation, visible focus states, adequate contrast, and do not rely on color alone.
