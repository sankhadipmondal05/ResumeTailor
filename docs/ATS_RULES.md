# ATS Formatting Rules

## Document

- Single column
- Normal document flow
- No tables
- No CSS columns
- No floating elements

## Contact

Keep contact information in the document body, not headers or footers.

## Section Names

Use standard headings:
SUMMARY
EXPERIENCE
PROJECTS
EDUCATION
SKILLS
CERTIFICATIONS

## Typography

Use Arial, Calibri, or Georgia. Avoid unusual display fonts.

## Dates

Prefer formats such as:
Jan 2024 – Present
Jan 2022 – Dec 2023

## Bullets

Use standard bullets.

## Links

Use readable URLs or recognizable text such as:
linkedin.com/in/name
github.com/name

## Graphics

Never use:
- skill bars
- charts
- percentages
- decorative icons
- logos
- headshots
- background images

## Default Resume

Black text on white background. Accent colors should be optional and restrained.

## Content Integrity

Never fabricate employment, education, skills, certifications, metrics, achievements, or experience.

## Keyword Tailoring

Incorporate keywords naturally. Never keyword-stuff.

## ATS Checklist

Optionally show:
- Single column
- Standard headings
- Selectable text
- No graphics
- Contact information in document body
- Standard dates

Never claim a guaranteed ATS score or 100% ATS compatibility.
